# Tic-Tac-Toe Game

[Play the Game](https://tic-tac-toe-game-7y3haw05b-harkirat19s-projects.vercel.app/)

## Description

This is a simple, interactive Tic-Tac-Toe game where two players can compete against each other. The game follows the classic 3x3 grid layout, and players take turns placing their mark (X or O) on the grid. The game detects when a player wins or if there's a draw. 

Key Features:
- Player name input for personalized play
- Turns alternated between Player 1 (X) and Player 2 (O)
- Dynamic updates to show whose turn it is
- Displays game comments with time and player actions
- Reset button to restart the game and clear the board
- Winner detection logic and game reset functionality

## Technologies Used

- **Frontend**:
  - HTML for the structure of the game page
  - CSS for styling and making the game visually appealing
  - JavaScript for handling game logic and interactions
